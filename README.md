# pandas-analysis-data-visualization

# 📊 Pandas & Data Visualization

## 📌 Project Overview

This project demonstrates **data analysis and data visualization using Python**.
The project is created in a **Jupyter Notebook** using Pandas, NumPy, Matplotlib, and Seaborn.

## 🛠️ Technologies & Libraries Used

* 🐍 Python
* 🐼 Pandas
* 🔢 NumPy
* 📈 Matplotlib
* 📊 Seaborn
* 📓 Jupyter Notebook

## 📂 Dataset

The project uses a **sales dataset containing 1000 rows and 14 columns**.

### Dataset Columns

* `Product_ID`
* `Sale_Date`
* `Sales_Rep`
* `Region`
* `Sales_Amount`
* `Quantity_Sold`
* `Product_Category`
* `Unit_Cost`
* `Unit_Price`
* `Customer_Type`
* `Discount`
* `Payment_Method`
* `Sales_Channel`
* `Region_and_Sales_Rep`

## 🔎 Data Analysis

The notebook performs different data analysis tasks, including:

* Loading the sales dataset
* Viewing the dataset
* Checking rows and columns
* Checking data types
* Checking missing values
* Generating descriptive statistics
* Grouping and analyzing sales data
* Using pivot tables for analysis

## 📊 Data Visualization

Different visualization techniques are used to understand the sales data:

* 📊 Bar Chart
* 📈 Line Chart
* 🔵 Scatter Plot
* 🥧 Pie Chart
* 📉 Histogram
* 📚 Stack Plot
* 🔥 Heatmap
* 📦 Boxplot

## 🎯 Project Objective

The main objective of this project is to **analyze sales data and present useful information through different data visualization techniques**.

This project helps in understanding how Python libraries can be used for **data analysis, comparison, trends, distributions, and relationships in sales data**.
